# Zip et les Gloops / Zip & the Gloops

A free, bilingual (French / English) learning game for kids around 5–7. Play it in any browser, no install, no account, no ads.

**Play:** https://mitchcharles21.github.io/zip-et-les-gloops/

## What's inside
- **Zip's path**: a short daily path (5 activities) that picks games the child needs to practice
- **Maths**: counting, numbers, adding, subtracting, more/less, patterns, clock, shapes
- **Reading**: letters, first letter, spell words, sight words, syllables, rhymes
- **Games**: road trip, race, colors, adventure with friends
- **Stories**: 7 short animated stories with comprehension questions
- **Paint**: free drawing with stamps and an eraser
- Stars, stickers, trophies, daily challenges and a little shop to dress up Zip

## Tips
- Use Safari or Chrome. Voices (text-to-speech) depend on the device, and may be silent in in-app browsers.
- Music and voice can each be turned off from the 🎵 button at the top right.
- Progress is saved on the device, in the browser (nothing is sent anywhere).
- On a phone: open the link, then "Add to Home Screen".

## Developing
Sources are in `src/`. Run `node build.js` to produce `index.html`.

# Français

Jeu éducatif gratuit, bilingue (français / anglais), pour les enfants de 5 à 7 ans. Il suffit d'ouvrir le lien dans un navigateur : pas d'installation, pas de compte, pas de publicité.

Les voix dépendent de l'appareil : utilise Safari ou Chrome. La musique et la voix se coupent séparément avec le bouton 🎵 en haut à droite. La progression est enregistrée sur l'appareil.
